# TrustNews architecture diagrams

## Component view

```mermaid
flowchart LR
    Client[Client / Frontend] --> Gateway[gateway]
    Gateway --> Handler[news-handler]
    Handler <--> Mongo[(MongoDB<br/>news, events, validations)]
    Handler --> Admin[admin<br/>quotas]

    Handler -- generate_assertions --> Kafka[(Kafka)]
    Kafka --> Generate[generate-asertions]
    Generate -- assertions_generated / assertions_not_generated --> Kafka
    Kafka --> Handler

    Handler -- upload_ipfs --> Kafka
    Kafka --> IPFS[ipfs-fastapi]
    IPFS --> IPFSStore[(IPFS)]
    IPFS -- ipfs_uploaded --> Kafka

    Handler -- register_blockchain --> Kafka
    Kafka --> Chain[news-chain]
    Chain <--> Contract[(Smart contract)]
    Chain -- blockchain_registered / validation_completed --> Kafka

    Contract -- ValidationRequested event --> Validate[validate-asertions workers]
    Validate --> IPFS
    Validate -- register validation tx --> Contract

    Handler -- light_validation_request --> Kafka
    Kafka --> Validate
    Validate -- light_validation_completed --> Kafka

    Validate -- RAG only<br/>POST /search/evidence --> Evidence[evidence-search]
    Evidence <--> Mongo
    Evidence --> Tavily[Tavily API]
```

## Data contracts

```mermaid
flowchart TD
    A[GenerateAssertionsRequest] --> B[assertions_generated]
    B --> C[assertions-document-v2]
    C --> D[EnrichedAssertion<br/>category + subcategory + context + search_hints]
    D --> E[to_chain_assertion]
    E --> F[Contract assertion<br/>idAssertion + text + categoryId]

    D --> G[assertion-validation-payload-v2]
    G --> H[validate-asertions]
    H --> I[ValidatorAPIResponse]
    H --> J[LightValidationResponse]
```

## Category boundary

```mermaid
flowchart LR
    OffChain[Off-chain protocol categoryId<br/>strict integer] --> ChainCat[On-chain categoryId<br/>registered catalog]
    ChainCat --> ContractSelection[Validator selection by categoryId]
    OffChain --> DomainRouter[Domain router<br/>categoryId/subcategory/context]
    DomainRouter --> EvidenceDomains[Preferred evidence domains]
```
